# auto-clicker
Basic Auto Clicker using Python

# Why
I was tired of malware links when trying to get a basic auto clicker.

# Installation and use

1. Clone repo using `git clone https://github.com/BuchnerEng/auto-clicker.git`
2. Initialize a Python venv using your favorite method. Ex: `python -m venv venv`
3. run `pip install -r requirements.txt`
4. run `python .\auto_clicker.py`
5. Start clicker using `*` navigate profiles using `[` and `]`, press `*` again to stop clicking or `Esc` to force exit the application.
